# Лабораторна робота 1: Моделювання бізнес-процесу в BPMN 2.0

**Варіант 15.** Оформлення пропуску для гостя бізнес-центру.

- **As-Is:** заявка по телефону, охоронець записує паспортні дані гостя в журнал.
- **To-Be:** заявка в системі, автоматична генерація та відправка гостю QR-коду, турнікет валідує код.

## Файли

| Файл | Опис |
|---|---|
| `Lab1_Variant15_AsIs.drawio` | Модель поточного стану (As-Is) у Draw.io |
| `Lab1_Variant15_ToBe.drawio` | Оптимізована модель (To-Be) у Draw.io |
| `AsIs.png` | Зображення моделі As-Is |
| `ToBe.png` | Зображення моделі To-Be |

## Як відкрити моделі

1. Перейдіть на [app.diagrams.net](https://app.diagrams.net).
2. Оберіть **File → Open from → Device** і виберіть потрібний `.drawio`-файл.

## Інструментарій

Draw.io (diagrams.net) з бібліотекою фігур BPMN 2.0.
